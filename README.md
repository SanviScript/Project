## 🛠️ Architecture & Tech

Built on a robust stack designed for performance and security:

- **Core Engine**: Streamlit for a reactive, lightning-fast user experience.
- **Intelligence**: Meta-Llama-3 via Hugging Face Inference API.
- **Storage**: Ephemeral SQLite integration for secure, local data handling.
- **Design**: Custom-injected CSS using `Plus Jakarta Sans` and `Outfit` typography.

## 🚀 Deployment Guide

### 1. Environment Setup
Clone the vault and install the core dependencies:
```bash
git clone https://github.com/yourusername/ai-insight-engine.git
cd ai-insight-engine
pip install -r requirements.txt
```

### 2. Ignition
Launch the engine:
```bash
streamlit run app.py
```

### 3. Authentication
Obtain a [Hugging Face API Token](https://huggingface.co/settings/tokens) and enter it into the dashboard sidebar to activate the AI modules.

## 💡 Quick Tips
- **Be Descriptive**: The AI works best when you specify what columns you want to see.
- **Check the History**: Click any previous query in the sidebar to re-run it instantly.
- **Upload CSVs**: You can upload multiple CSVs; each one becomes a new table in the engine.
